# Grade-Management
Introduction

The Grade Management System is a simple Python-based command-line application designed to manage student grades. It allows users to add, update, delete, and view student records through an interactive menu.

This project demonstrates the use of fundamental Python programming concepts and basic CRUD operations.

Features:- 
1. Add a new student with their grade
2. Update an existing student's grade
3. Delete a student record
4. View all student records
5. Simple menu-driven interface

Technologies Used:-
1. Python 3
2. Python Dictionary
3. Functions
4. Conditional Statements
5. Loops
6. User Input

Concepts Demonstrated:-
1. Dictionary-based data storage
2. Functions and modular programming
3. if-elif-else statements
4. while loop
5. CRUD operations
6. Basic user interaction

How It Works:-

Student names and grades are stored in a Python dictionary:

student_grades = {}

The program provides five options:

1. Add Student
2. Update Student
3. Delete Student
4. View Student
5. Exit

The selected operation is performed based on the user's input.

How to Run:- 
1. Prerequisite
      Make sure Python 3 is installed on your system.

2. Check the installation:
      python 3.10.14 or 3.10.12 version

3. Run the Project
      python grade_management.py
